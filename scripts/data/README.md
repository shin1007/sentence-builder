# scripts/data

## cefrj-vocabulary-profile-1.5.csv

語彙のレベル点検（`npm run vocab:audit`）で使う CEFR-J Wordlist です。アプリ本体には含めず、点検スクリプトからだけ読みます。

- 出典: The CEFR-J Wordlist Version 1.5. Compiled by Yukio Tono, Tokyo University of Foreign Studies. Retrieved from http://www.cefr-j.org/download.html
- 入手元: https://github.com/openlanguageprofiles/olp-en-cefrj （`cefrj-vocabulary-profile-1.5.csv`）
- 利用条件: 出典を明記すれば、研究・商用ともに無償で利用できます。著作権は東京外国語大学 投野由紀夫研究室に帰属します（入手元の README の Terms of use より）。
